# Gezi

Tur, blog ve iletişim sayfaları olan gezi sitesi.

## Ne var

Ana sayfa, blog, hakkında ve iletişim controller'ları vardır.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework MVC, Entity Framework ve Code First.
